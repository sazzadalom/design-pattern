# design-pattern
Design pattern is a reusable proven solution to commonly occuring is software development problems.
Design Patterns

 <H1>Creational Design Patterns</H1>

<p> 1. Singleton Pattern
	Ensures that a class has only one instance and provides a shared access point to it.
	Example: A shared configuration object.</p>

<p> 2. Factory Method Pattern
	Lets subclasses decide which concrete object to create through a common creation interface.
	Example: Creating different notification types.</p>

<p> 3. Abstract Factory Pattern
	Provides an interface for creating families of related objects without specifying their concrete classes.
	Example: Creating related UI components for different themes.</p>

<p> 4. Builder Pattern
	Constructs complex objects step by step.
	Example: Building a MovieBooking object with optional fields.</p>

<p> 5. Prototype Pattern
	Creates new objects by copying an existing object.
	Example: Copying a pre-configured template object.</p>
